IOTA for Windows

Skills Library

Skills are add-ons for specific jobs. You start one by typing its slash command in a chat, for example /chart. The skill does the work with tested code, and IOTA writes the reply around the result.

There are two kinds. Skill packages are zips with the skill files that ship with IOTA for Windows, ready to install. .md skill guides are detailed written instructions, by IOTA - Joseph Bryant, that you paste into an IOTA chat or follow yourself. Guides do not install anything. Most skills run offline; the cards say which ones need the internet.

How to

How to install a skill package

Each download is a small zip with the skill's Python files, a skill.json file that describes it, and an INSTALL.txt file with these steps. Model files are not included. The skills in this library are the same files that ship with the V1.2 kit, so you can also use a download to restore or update a skill.

  1. Download the skill. To check the file, open PowerShell in your Downloads folder and run Get-FileHash .\iota-skill-chart-1.2.zip -Algorithm SHA256 with the file name of your download. The result should match the SHA-256 on the skill's card.
  2. Close IOTA.
  3. Back up your skills folder. In the PowerShell edition it is scripts\skills inside the IOTA kit. In the EXE edition it is skills-py next to IOTA.exe.
  4. Open the zip and copy everything inside its files folder into that skills folder. Replace files when Windows asks.
  5. Start IOTA. Open the Developer rail, then Skills, then Check libraries, to confirm the skill's libraries are ready.
  6. Type the slash command in a chat, for example /chart bar of sales by month.

How to use a .md skill guide

A guide is a Markdown text file. It tells the model in IOTA how to do one job step by step, with the commands, code, checks, and safety rules to follow. It is not a compiled program and it does not add a feature to IOTA on its own. Each guide starts with a header that lists the command, the editions it fits, whether it needs the network, and the credit to IOTA - Joseph Bryant.

  1. Download the guide with Download .md, or read it first with View. To check the file, run Get-FileHash .\iota-skill-spc.md -Algorithm SHA256 with the file name of your download and compare it with the SHA-256 on the card.
  2. Open the file in any text editor and copy its text.
  3. Paste it into an IOTA chat, then give your request on the next line, for example /spc bore.csv spec 24.95 to 25.05.
  4. Each guide tells IOTA to show its plan and ask before it changes or overwrites a file. Larger models follow long guides more closely; each guide lists what it needs.

Skills marked PowerShell edition only use tools and model files from the USB kit, such as the OCR and speech models. Replies from AI can be wrong. Check the results before you rely on them.
