IOTA Mobile

Info banks

Info banks are optional offline reference packs for IOTA Mobile. The phone downloads only the ones you check in Developer settings, then searches them when a question needs a fact. They are not mixed into every reply.

This page lists every bank, with its size, license, attribution, build date, and SHA-256. The app reads manifest.json. Small packs are files on this page. A pack that would push the site past about 900 MB is a GitHub Release asset on this same repository, tag infobanks-v1, in parts under 95 MB.

Built 2026-11-09. Device date and Online results override a bank when they disagree.

On the phone

How a bank gets onto the phone

You do not copy these files by hand. IOTA Mobile downloads them.

  1. Open IOTA Mobile, then Settings, then Developer, then Info banks.
  2. Check the banks you want. Save changes downloads them on Wi-Fi, checks each part's SHA-256, joins the parts, and keeps the pack on the phone.
  3. Uncheck a bank and tap Save changes to delete it.
